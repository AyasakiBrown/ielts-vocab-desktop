# 雅思词汇听写合集

本地离线词汇练习工具，包含 Part 1 高频词、词汇真经、听力场景词汇、生词本及错词本；生词支持听力、阅读、写作、口语分类和专项练习。

## 下载与运行

- macOS：解压 macOS-universal 包，把「雅思词汇听写合集.app」拖到应用程序目录。支持 macOS 13 及以上、Apple Silicon 和 Intel。使用本地 ad-hoc 签名，未经过 Apple 公证；首次打开可能被系统拦截，请在确认下载来源后使用系统「隐私与安全性」中的打开选项。
- Windows：解压 Windows-x64 包，双击 IELTSVocab.exe。保留整个解压文件夹，不能单独移动 exe。内置 Electron，无需安装 Python 或 Node.js。面向 Windows 10/11 x64；未做发布者签名，系统可能显示未知发布者。此包在 Mac 上组装，Windows 真机运行、发音和重启保存仍待验证。
- 发音依赖系统提供的英语语音。离线发音需要已安装本地英语语音包。

## 数据与隐私

发布包仅包含程序及内置学习素材，不包含作者的学习进度、个人生词、错词、账号信息、同步证书、私钥、主机名或个人目录配置。

Mac 数据存放在当前用户的 `~/Library/Application Support/IELTSVocab/data.json`；Windows 数据存放在当前用户 `%APPDATA%/IELTSVocab/data.json`；首次运行 v1.0.3 会自动迁移 v1.0.2 的应用浏览器存储。重新打开会保留记录；清除应用数据会删除记录，卸载前可备份整个数据目录。已经使用同一应用的 Mac 用户会继续看到自己的已有记录。

本次发布为桌面离线版，不附带局域网同步服务器或 iPhone 安装配置，不启动监听端口。Windows 程序阻止网页 HTTP/HTTPS/WebSocket 请求，无云端上传或统计模块。系统语音服务的行为取决于用户的系统与语音配置。

## 分享到 GitHub

把两个平台的 zip 及 SHA256SUMS.txt 上传到 GitHub Releases。需要分享源代码时，解压 Source 包，将其内容作为仓库根目录上传。不要上传原开发目录、个人数据目录、学习备份或同步文件。

源码包采用明确文件白名单；构建脚本检查个人路径、常见令牌、私钥及固定局域网地址；zip 使用固定时间戳且不包含 Finder 扩展属性。自动扫描不能代替对自由文本内容的人工判断。

内置词书内容、词典和图片的再分发授权尚未核实。本包未替这些第三方素材声明开源许可；公开分享前应确认相应授权。

## 从源码构建

在安装 Xcode 命令行工具、Python 3、curl 的 Mac 上执行：

```sh
python3 release-tools/build_release.py
```

本机开发构建（只生成当前架构的 Mac 应用）：`./build.sh`。

测试：`node release-tools/test-srs.cjs`、`node --test release-tools/test-learning-data.cjs`、`python3 release-tools/test_native_data.py`；界面测试（`test-mistakes.cjs` 等）需要 Playwright 与本机 Chrome。

发布构建要求 `src/`、`release-tools/` 已提交，并把提交号写入 `SOURCE_COMMIT.txt`；版本与源码提交的对应见 `release-tools/VERSIONS.md`。

输出到 `GitHub-Release/`。脚本构建 Mac 通用二进制，并下载固定版本 Electron 44.3.0 的 Windows x64 官方运行时，使用官方 SHA-256 清单校验。保留 Electron 自带许可证文件。

Windows 使用 Electron 官方的[手动分发方式](https://www.electronjs.org/docs/latest/tutorial/application-distribution)。当前不提供自动更新。

## v1.0.2：可编辑快捷键

打开软件菜单「帮助 → 快捷键设置」，点击某项键位并按下新组合，再点击「保存设置」。可清除单项键位、取消本次修改，或恢复默认后保存。冲突键位无法录入；复制、粘贴、退出等系统快捷键保留默认。

页面切换、重听、前后题、提交/添加、翻面、关闭练习、缩放及设置入口均支持自定义。设置即时生效，原绑定失效；默认表仅供首次使用参考。Mac 和 Windows 分别保存自己的配置，跟随本地应用数据保留到下次启动。即使清除了设置入口快捷键，也可从「帮助」菜单打开。

只有按键焦点位于软件页面内时才执行自定义键位；操作系统占用的组合键可能无法被软件接收。Mac 设置保存在本地配置中；Windows 设置保存在应用用户存储中，均不随发布包附带作者的个人配置。


## v1.0.3：完整备份、恢复与学习记录

菜单「学习数据 → 学习记录与数据转移」集中查看每日统计、导出完整备份及恢复数据。

### 更新软件，保留原记录

1. 在旧程序中完成当前答题并关闭练习。v1.0.3 及以后可先选择「导出完整备份」。
2. 退出软件，替换 Mac 应用或完整解压新版 Windows 程序。
3. 使用同一系统账户打开新版。不要删除应用数据目录、使用清理工具清空数据，或同时运行旧版和新版。

数据目录不包含版本号，替换程序不会删除记录。Windows 首次升级到 v1.0.3 会读取原来的浏览器存储并写入独立 data.json；请保留原数据目录。Mac 继续使用已有 data.json。Windows 真机升级验收仍待完成。

### 换电脑或跨系统转移

在原电脑选择「导出完整备份」，将生成的 JSON 文件传到新电脑，然后选择「从备份恢复」。预览条目数量后确认恢复。此操作完整替换新电脑当前的数据，不合并；恢复前会自动备份原数据，备份失败则停止恢复。可从「打开自动备份目录」找到原记录并再次恢复。

备份涵盖三个词库的进度、收藏、答题累计与每日统计，生词及听力/阅读/写作/口语分类，错词、删除记录、设置，以及 Mac/Windows 各自的快捷键。不会将一套系统快捷键强制改成另一套；新系统未配置时使用默认键位。尚未提交的练习不在备份中。

导入支持本版完整备份和旧 Mac 的 v1 data.json。单词库的「导出进度」文件仍在对应词库中导入，不是完整备份。损坏文件、不支持的版本及超过 32 MB 的备份会被拒绝。

### 自动备份与历史

修改数据前每天保留一份旧状态，最多保留最近 30 份每日备份；恢复前备份不会自动清理。备份位于应用数据目录的 backups 子目录。自动备份与原数据在同一磁盘，换电脑、卸载或磁盘故障前请另行导出到其他安全位置。

从 v1.0.3 开始保存三个词库每日完成和正确题数，重复保存不会重复计数。旧版只保存当日统计，未记录的过去日期无法补回；每日统计不涵盖生词本专项练习。

完整备份包含使用者的个人学习内容，请勿随程序上传到 GitHub。程序发布包仍不附带作者的学习记录和备份。


## v1.1.0：今日复习、跨天掌握与错因针对训练

### 复习机制

- **今日复习**：首页「📅 今日复习」或菜单「词库 → 今日复习」（默认 ⌘6 / Ctrl+6）。三个词库、生词本、错词本按单词合并为一份复习记录，到期的词进入统一队列，每日上限默认 60，可调整；超出部分逐天放出。
- **跨天掌握**：听写（听到能拼）与选择题（看见能懂）分开记录。只有在到期日、且与上次答错或提示不在同一天时无提示答对才升级；复习间隔为 1/3/7/14/30 天。答错降级并当天重练，当轮隔几题重测。旧版「已掌握」变为「待复核」，通过一次无提示复测后继续计入。
- **英式、美式拼写都判对**：使用经核实的对照表（colour/color、centre/center、organise/organize、travelling/traveling 等），不再按字母规律放行 caer、corse、exercize 这类错拼。字母正确但空格或撇号有误时提示标准写法，本次不计入掌握；使用首字母提示后答对同样不计入。
- **较新的答案优先保存**：词库进度与复习记录按答题时间合并，较新的记录覆盖较旧的，避免旧页面或重复保存覆盖新进度。

### 错因诊断与针对训练

听写答错后显示「🔎 错因」，并标出正确拼写中的出错片段。错因分为双写字母、元音、辅音、字母顺序、漏字母、多字母、词尾、多处拼写、词形、听成另一个词、同音词、整词没拼出、短语不完整及词义混淆。

「今日复习」页的「🎯 针对训练」按错因分组练习（每组 8 个词，错 2 次以上优先）。训练本身不提升掌握等级；练过的词次日无提示复测，通过后才升级。

### 升级与备份兼容性

升级保留原有进度、错词和每日记录，错词自动排入复习。数据文件新增 `decks.srs`（复习记录），完整备份包含该记录。**v1.1.0 导出的完整备份无法在 v1.0.3 及更早版本中恢复**；旧版备份仍可在新版中恢复。更新前建议先在旧版导出一份完整备份。
