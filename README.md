# 雅思词汇听写合集

支持 Windows 和 macOS 的离线桌面工具，包含听写、生词本、错词本，以及听力、阅读、写作和口语分类练习。学习数据保存在本地。

## 安装与首次打开

**Windows：** 完整解压后双击 `IELTSVocab.exe`，请保留同文件夹的其余文件。

**Mac：** 解压后将应用拖入“应用程序”。本版仅本地签名，尚未获得 Apple 公证。若提示“无法验证开发者”或“Apple 无法检查是否包含恶意软件”，确认下载来源后先尝试打开一次，再前往 **系统设置 → 隐私与安全性 → 仍要打开**。无需关闭系统整体安全保护。

发音依赖系统英语语音；离线发音需已安装本地语音。

## 可编辑快捷键

Windows 和 Mac 均可通过 **帮助 → 快捷键设置**（默认 F1）修改键位：点击某项键位，按下新的组合键，再点击“保存设置”。

支持冲突提示、单项清除、取消修改和恢复默认；保存立即生效，重启后保留。编辑菜单与右键菜单使用中文。Mac 已实测修改键位、旧键失效和重启保存；两平台配置逻辑测试通过。
